What this site counts

OpenKingdoms counts visits to this site so the person who runs it can see how many people come by, how many of them play, and which parts of the game get used. This page lists everything that is counted and everything that is not.

What is counted

  • A visit to each page of the site.
  • How far a visit got. The game files were chosen, the main menu came up, a battle started.
  • Each battle's kind (campaign, skirmish, multiplayer, a replay or a loaded game), its map or mission, the number of computer players and how hard they were, whether the Remastered Battlefield option was on, the mod set, the side you played, how long it lasted and how it ended.
  • The message the game shows when it stops with an error.
  • Your browser family, your system family, whether it is a phone or a tablet, a rough screen size, and which of the game server's regions your browser reached.

How a visitor is counted once a day

Your browser makes up a random number and keeps it in its own storage for this site. The number says nothing about you. The game server mixes it with a key that changes every day and keeps the mixed form only to count each visitor once that day. The list goes at midnight UTC. If the server restarts during the day it keeps that list on disk while it is down and deletes it as it starts again. After the day is over all that is left are the day's totals, such as 40 visitors and 12 skirmishes on one map.

What is never collected

No cookies are set and no IP address is stored. To stop one machine from flooding the counts, the game server holds a scrambled form of the address in memory for one minute, and then it is gone. No names, chat or game files are collected. Nothing is sold or shared, and no other company tracks anyone on these pages. The desktop builds of the game send nothing at all.

The pages are hosted on GitHub Pages and the game server runs on fly.io. Like any web host they see your IP address when your browser connects, under their own privacy policies. The pages also load their two typefaces from Google Fonts.

The multiplayer leaderboard is a separate thing. It lists finished multiplayer games with the names the players typed into the game, and all of it is on that page for anyone to see.

Turning it off

If your browser sends Do Not Track or Global Privacy Control, nothing is counted and nothing is sent. You can also turn the counting off for this browser below. The choice is kept in this browser until you clear its data for this site.
