# Radar (2026-10-21)

Issue #319. `radardistance` is set by 71 of the 155 base unit files,
mostly 400 to 1000 px, with the dragons and gods at 2000. Sight on the
same units is 145 to 500, so radar reaches two to four times further.
The engine read the key and never used it. This note records what the
original does with it and what the engine now does.

## The original

The key is read into the unit definition beside `sightdistance`
(legacy:162920-162923). Its one reader in play is the pass that marks
which units the local viewer sees on the minimap. It runs once a tick,
only with more than one player, and starts from nothing each time
(legacy:208607-208710).

1. Every mark is cleared and the viewer's own units are marked
   (legacy:208630-208641).
2. Each of the viewer's own units that is alive, not on its way out,
   finished and has a `radardistance` marks every unit within that
   radius (legacy:208642-208655). The circle is flat, on world
   positions, with no height and no line of sight (legacy:220374-220455).
   A unit is marked only when it belongs to another player and is not
   cloaked (legacy:208580-208590).
3. Units are revealed by cloak distance (legacy:208656-208676).
4. Any unit still unmarked is marked when its ground is in the viewer's
   sight, or explored with Line of Sight off (legacy:208677-208706).

The minimap and the full screen radar draw the marked units, a blip each
in the owner's colour (legacy:208470-208526). The main view tests the
fog maps alone and never the mark (legacy:206797). Targeting, the
computer players and the rest of the simulation never read it.

So radar shows other players' units as blips beyond sight and nothing
more. Only the viewer's own radar counts. An ally's is not shared. A
nanoframe has none, and switching a unit on or off does not matter. With
the Mapping and Line of Sight options both off the minimap draws every
unit anyway (legacy:208462-208466).

## What the engine does

`Units_RadarShowsToLocalPlayer` in `src/render/units.c` builds the radar
marks for the seat the screen shows, once a simulation tick when the
minimap asks, from the unit grid. The minimap, the full screen radar and
a save's thumbnail draw a unit that the viewer sees or that radar marks.
The main view, picking and the simulation are unchanged, so the state
hash is too.

The original's minimap pick reads the units it drew, so a radar blip
can be pointed at. The engine's minimap has no unit pick, so there is
nothing to change there.
